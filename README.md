# Quest Launcher

Переносимый Windows-лаунчер для создания и запуска EXE-копий под выбранным именем. Автор: **vaelit**.

## Скачать

Готовая сборка находится в [Releases](https://github.com/NekoPoint/QuestLauncher/releases). Скачайте `QuestLauncher-1.4.0.zip`, распакуйте его в доступную для записи папку и запустите `QuestLauncher.exe`. Установка не требуется.

Поддерживаются Windows 10/11 с .NET Framework 4.8. Для запуска не нужен .NET SDK.

## Использование

1. Введите имя EXE, например `Endfield.exe`, и выберите папку назначения.
2. Проверьте итоговый путь и нажмите «Создать и запустить».
3. Созданная копия появится в библиотеке. Для старых файлов нажмите «Импорт».
4. Меню «…» содержит запуск, обновление, «Обновить все», избранное, открытие папки, копирование пути и удаление.

«Обновить все» обрабатывает всю библиотеку, включая скрытые поиском и фильтрами записи. Занятые, изменённые, отсутствующие и неподтверждённые файлы не обновляются автоматически.

Секундомер в окне копии показывает время работы процесса. Он не подтверждает выполнение квеста в Discord. Окно автоматически не закрывается.

## Обновление

Закройте лаунчер и запущенные копии. Замените основной EXE новой версией, сохранив `launcher.cfg`, `QuestLauncher.library` и папки копий. Старые копии можно импортировать в библиотеку и обновить через «… → Обновить все».

При незавершённом обновлении сохраните файлы `.qlbak`: они нужны для восстановления. Лаунчер предложит восстановление с подтверждением и сохранением текущего файла.

## Сборка

```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```

Нужен компилятор .NET Framework 4.x (`csc.exe`); скрипт проверяет его наличие. Скрипт собирает приложение и тестовый раннер, запускает 22 проверки во временной папке и формирует контрольные суммы. Результат находится в `dist/`, основной EXE также копируется в корень проекта. Перед сборкой закройте запущенный корневой лаунчер.

`-SkipTests` пропускает запуск проверок. Обычная сборка не имеет релизной подписи. Слот QLSG1 служит для внутренней проверки сборок и не является Windows Authenticode; настройка официального ключа требует отдельного релизного процесса.

## Структура

```text
src/                    исходники
tests/                  проверки и исторические бинарные фикстуры
assets/lucide/          SVG, подготовленные PNG и лицензия иконок
.github/workflows/      автоматическая сборка и проверки
QuestLauncher.csproj    проект .NET Framework 4.8
build.ps1               сборка
CHANGELOG.md            изменения версии
```

Настройки, библиотека и журнал хранятся рядом с EXE; если папка недоступна для записи — в `%LOCALAPPDATA%\QuestLauncher`. Личные файлы данных и созданные копии не входят в репозиторий.

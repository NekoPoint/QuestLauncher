# Discord Quest Launcher
  ![Downloads](https://img.shields.io/github/downloads/NekoPoint/QuestLauncher/total)

Прога для быстрого выполнения квестов в Discord без скачивания игр по 100 ГБ.

Создает процесс с нужным именем игры, жрет 0% проца и 12 (+-) МБ оперативы.

### Как пользоваться
1. Запускаешь `QuestLauncher.exe`
2. Вводишь имя игры (например `Endfield` или `FortniteClient-Win64-Shipping.exe`, можно найти в интернете)
3. Жмешь **Запуск**
4. Если в квесте просят стримить стримишь открывшееся окно 15 минут (такое бывает)
5. Забираешь награду в дискорде и закрываешь окно
